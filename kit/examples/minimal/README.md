# Пример: минимальный дашборд (продажи)

Короткий пример из другого домена — интернет-магазин, один CSV-источник,
4 KPI, 2 графика, 1 таблица. Доказывает, что кит работает не только на
сложных 7-источниковых кейсах.

## Ситуация

- Источник: один файл `orders.csv` с выгрузкой из CRM.
- Столбцы: `order_id`, `customer_name`, `channel`, `status`, `amount_usd`, `created_at`.
- Пользователь: владелец магазина, смотрит на десктопе.
- KPI: выручка, клиенты, средний чек, доля возвратов.
- AI-ассистент: включён, OpenAI API.
- Прогноз: на выручку по месяцам.

## Файлы рядом

- [source-manifest.yaml](source-manifest.yaml)
- [metric-catalog.yaml](metric-catalog.yaml)
- [brand.config.yaml](brand.config.yaml)
- [ui-layout.yaml](ui-layout.yaml)
- [orders.sample.csv](orders.sample.csv) — 20 строк фейковых данных для самопроверки.

## Как пройти QUICKSTART на этом примере

1. Создайте пустой проект `demo-dashboard/`.
2. Скопируйте `kit/` в `demo-dashboard/kit/`.
3. Скопируйте 4 YAML-файла и CSV из этой папки в корень `demo-dashboard/`
   (CSV — в `demo-dashboard/data/orders.csv`).
4. Откройте `demo-dashboard/` в Cursor.
5. Отправьте агенту [prompts/00-master.md](../../prompts/00-master.md).
6. Скажите агенту: «Конфиги уже лежат в корне, discovery пропускай. Начни с
   kit/prompts/20-map-data.md».
7. Дальше идите по шагам QUICKSTART (20 → 30 → 40 → 50 → 90).

Ожидаемый итог за 15–20 минут:

- `data/dashboard.json` с 4 заполненными KPI и 2 графиками.
- Открытый в браузере дашборд на Vanilla HTML+JS+ApexCharts.
- Рабочий чат с ассистентом: «Какой средний чек?» → «факт → вывод → действие».
- Прогноз выручки на 3 месяца во вкладке «Прогноз».

## Что этот пример показывает

- Минимальная конфигурация: 1 источник, 4 метрики, 2 графика.
- Полный AI-ассистент работает с тем же набором инструментов.
- `ui-layout.yaml` с 3 вкладками (Сводка / Детализация / Прогноз).
- Те же skill-файлы кита отлично работают на новом домене без правок.
