# FAQ

Топ-20 вопросов, которые возникают при работе с китом.

## О ките в целом

### 1. Это готовый продукт или шаблон?

Это не шаблон кода, а **Prompt Kit** — набор инструкций для AI-агента. Код
вашего дашборда генерирует агент по промтам из `prompts/`.

### 2. Какой стек получится на выходе?

Любой, который вы выберете. По умолчанию — Vanilla HTML+JS+CSS + ApexCharts.
На выбор: React, Vue, Svelte, Streamlit, Dash. Бэкенд — Node (Express/Fastify)
или Python (FastAPI/Flask).

### 3. Нужно ли уметь программировать?

Нет. Достаточно уметь читать и править YAML-файлы. Код пишет агент.

### 4. Как много времени занимает сборка?

Обычно 25–45 минут по [QUICKSTART](QUICKSTART.md). При большом количестве
сложных источников — до 2 часов.

## Данные

### 5. Сколько источников поддерживается?

Любое количество. В `source-manifest.yaml` вы можете описать 1 источник, 7,
20, 50 — агент соберёт их все в один `dashboard.json`.

### 6. Какие форматы источников поддерживаются?

Excel (xlsx/xls), CSV/TSV, JSON, Parquet, SQLite, Postgres, MySQL, HTTP API,
Google Sheets. Любой формат, который понимает pandas (для Python-стека) или
стандартные Node-библиотеки.

### 7. А если у меня данные в 1С / SAP / другой ERP?

Выгрузите во что-то из п.6 (обычно Excel или CSV). Прямой коннектор к 1С/SAP
не входит в кит — его при необходимости допишет агент отдельным источником
kind `api`, если у вас есть их REST.

### 8. Как часто пересобирать `dashboard.json`?

Зависит от сценария. Минимум — раз в сутки, через cron или CI (см.
`prompts/99-fix.md -> Шаблон G`). Данные, которые меняются редко —
вручную по кнопке.

### 9. Что делать с персональными данными?

Никогда не коммитьте реальные данные в git. Папку `data/` добавляйте в
`.gitignore`. Храните файлы в защищённом хранилище или генерируйте
`dashboard.json` на CI и публикуйте только его.

## Метрики

### 10. Как описать формулу KPI, если она сложная?

Опишите словами. Агент поймёт естественный язык и превратит в код. Пример:
`"Выручка за последние 30 дней минус выручка за предыдущие 30 дней, делённая на выручку за предыдущие 30 дней"` работает. Точная нотация (`sum(...)`,
`avg(...)`) приветствуется, но не обязательна.

### 11. Как задать пороги «зелёный/жёлтый/красный», если нет бенчмарка?

Используйте `baseline` — это автоматически вычисляемая базовая линия
(средний полный срез данных). Например,
`target: "> baseline * 1.05"` = «выше базовой линии на 5%». Со временем,
когда появятся бизнес-цели, замените на абсолютные значения.

### 12. Можно ли переименовать KPI без переписывания кода?

Да. Измените `label` в `metric-catalog.yaml` — UI обновится. Если меняется
`id`, нужно синхронно поменять и `ui-layout.yaml -> kpi_block.cards[].ref`.

## UI

### 13. Как изменить только цвет, не трогая всё остальное?

Поправьте нужное поле в `brand.config.yaml -> palette`. Агент по промту
`99-fix.md -> Шаблон B` перегенерирует только CSS-переменные.

### 14. Как добавить собственный шрифт?

Укажите `typography.font_family` в `brand.config.yaml`. Если шрифт есть на
Google Fonts — агент подключит его автоматически. Для корпоративного шрифта
положите файлы в `assets/fonts/` и скажите агенту «подключи локальный шрифт».

### 15. Почему на мобильном всё скачет?

Скорее всего, не пройден §7 чек-листа (адаптивность). Отправьте промт
`99-fix.md` и опишите проблему — агент пройдётся по брейкпоинтам.

## AI-ассистент

### 16. Нужен ли облачный LLM?

Нет. Можно работать в локальном fallback — ассистент будет отвечать только
по точным агрегатам `dashboard.json`. Это бесплатно и без внешних запросов.

### 17. Ассистент выдумал число — что делать?

Используйте `prompts/99-fix.md -> Шаблон E`. Агент ужесточит системный
промт и добавит регрессионный тест.

### 18. Как ограничить, что ассистент может рассказывать?

В `brand.config.yaml -> assistant.answer_format` и в
`skills/dashboard-assistant/SKILL.md` — секция «Запрещено». Добавьте свои
ограничения и перегенерируйте промт агента.

## Прогноз

### 19. Сколько исторических точек нужно для адекватного прогноза?

- Минимум 12 точек для базового прогноза;
- 18+ для ETS с сезонностью;
- 24+ для SARIMAX. Если точек меньше — работает fallback, но точность ниже.

### 20. Что делать, если Python недоступен на сервере?

Агент подключит JS-fallback (линейная регрессия + сезонный компонент) с
пометкой `model_info.fallback: true`. Это менее точно, но не блокирует
пользовательский опыт.

## Windows-runtime

### 21. `npm run …` / `.ps1` ругается на execution policy

PowerShell по умолчанию блокирует запуск неподписанных скриптов. Решения:

- Разово для текущей сессии:
  ```powershell
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  ```
- Постоянно для пользователя:
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
  ```
- Или запускать скрипт через `cmd` (`.cmd`-обёртка), а не напрямую `.ps1`.

### 22. «Порт занят» при старте API/статического сервера

Обычно висит процесс с предыдущего запуска. Проверка и убийство:

```powershell
# найти, кто держит порт 5173 или 8787
netstat -ano | Select-String ":5173 "
netstat -ano | Select-String ":8787 "

# убить процесс по PID из последней колонки
Stop-Process -Id <PID> -Force
```

Если стабильно висит — в скрипте запуска добавь шаг «освободить порт
перед стартом». Либо используй `npx kill-port 5173 8787`.

### 23. Старый `node` / `py` «не видит» новые файлы

Это кэш nodemon/webpack-dev-server или открытый файловый дескриптор.
Останови процесс (см. 22), затем заново запусти. Никогда не коммить
изменения, пока процесс висит — получишь ощущение «ничего не поменялось».

### 24. UTF-8 в консоли PowerShell (кракозябры в логе)

```powershell
chcp 65001                        # кодировка консоли на UTF-8
$OutputEncoding = [Text.UTF8Encoding]::new()
[Console]::OutputEncoding = [Text.UTF8Encoding]::new()
```

Добавь это в `.ps1`-обёртку запуска дашборда — кириллица в логах станет
читаемой на любой машине.

### 25. Cyrillic имена колонок из Excel не находятся маппером

Проверь три вещи:

- имя в `source-manifest.yaml -> mapping.columns` должно совпадать с Excel
ПОСИМВОЛЬНО, включая регистр и пробелы (не транслитерируй);
- лист в xlsx сохранён в UTF-8 (xlsx по умолчанию — да, xls — нет, конверт
в xlsx);
- кодировка консоли, в которой ты запускал билд, не влияет на сам
dashboard.json (см. 24 — это только про лог).
