# 06. Прогноз — временные ряды on-demand

Этот шаг опционален. Он добавляет в дашборд инструмент `forecast_metric`,
которым пользуется агент, и отдельный график прогноза во вкладке, если
он описан в `ui-layout.yaml`.

## Что делает `forecast_metric`

- Принимает id ряда (`metric`) из `metric-catalog.yaml -> series`, помеченный
  `forecastable: true`.
- Строит модель (ETS, SARIMAX, или fallback) по истории ряда.
- Возвращает точечный прогноз на `horizon` (1..12), доверительный интервал,
  метрики качества (`MAE`, `RMSE`, `MAPE`).
- Возвращает готовые артефакты (`table` и `chart`) для UI.

## Что вам подготовить

1. Пометьте ряды, по которым хотите прогнозировать:

   ```yaml
   series:
     - id: revenue_monthly
       label: "Выручка по месяцам"
       forecastable: true
       x: { field: "month", kind: "time" }
       y: { field: "total", unit: "USD" }
   ```

2. Убедитесь, что в `dashboard.json -> datasets.<id>` есть история ряда.
   Минимум — 12 точек. Для ETS желательно 18+, для SARIMAX — 24+.

3. Опционально добавьте во вкладку `ui-layout.yaml` график:

   ```yaml
   tabs:
     - id: forecast
       label: "Прогноз"
       charts:
         - id: chartRevenueForecast
           kind: "line"
           title: "Прогноз выручки"
           bind: "charts.revenue_forecast"
           supports: ["actual", "forecast", "confidence_interval"]
   ```

## Как подключить

Отправьте агенту [prompts/50-forecast.md](../prompts/50-forecast.md). Агент:

1. Добавит инструмент `forecast_metric` в бэкенд (см. `skills/agent-tools`).
2. Подключит Python-движок (если выбран Python) или JS-движок прогноза.
3. Прогонит smoke-тест (короткий пайплайн «ряд → прогноз → артефакт»).
4. Добавит в UI отрисовку прогнозных серий с визуальным различием
   факт / прогноз / интервал.

## Правила ответов

- В ответе ассистента прогноз явно маркируется как **расчётная оценка**.
- Если пользователь не указал горизонт, агент использует 3 периода и явно
  говорит об этом.
- Если движок прогноза недоступен (нет Python / отсутствует `statsmodels`),
  возвращается управляемый fallback, а не 500-ошибка.

## Smoke-тест

Минимальные команды, которые агент подготовит:

- `smoke:forecast` — запускает пайплайн «ряд → прогноз» вне UI и печатает
  `OK` + краткий JSON с качеством модели.

## Критерий готовности

- `smoke:forecast` проходит и возвращает `OK`.
- В UI во вкладке «Прогноз» появляется график с тремя логическими слоями
  (факт, прогноз, доверительный интервал).
- Ассистент корректно отвечает на вопрос «Спрогнозируй <метрику> на N месяцев».
- При нехватке истории выдаётся понятная ошибка, а не падение.
