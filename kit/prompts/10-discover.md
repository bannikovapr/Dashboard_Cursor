# 10 — Discovery (сбор требований)

Используется сразу после [00-master.md](00-master.md). Агент задаёт вопросы
блоками и записывает ответы в `PROJECT_BRIEF.md`.

---

```
Режим: discovery. Действуй по kit/playbook/01-discovery.md и kit/skills/data-mapper/SKILL.md.

Задай мне ниже перечисленные блоки ПО ОДНОМУ, дождись ответа, запиши в
PROJECT_BRIEF.md и только потом переходи к следующему блоку. Формулировки —
короткие, не более 3 пунктов на блок. Используй разумные дефолты, если я
отвечаю «не знаю».

Блоки:

1. АУДИТОРИЯ И ЦЕЛЬ
   - Кто основной пользователь дашборда?
   - Какое решение он принимает по нему?
   - На каком устройстве чаще всего смотрит (десктоп / планшет / мобильный)?

2. ДОМЕН И ТЕРМИНОЛОГИЯ
   - Короткое описание домена (1 предложение).
   - 3–5 терминов, которые важно использовать как их привыкли называть у меня.

3. ИСТОЧНИКИ ДАННЫХ
   - Что есть сейчас: файлы (Excel/CSV/JSON), Google Sheets, БД (какая), API?
   - Сколько источников и как они расположены (путь / URL / DSN).
   - Как часто обновляются.

4. МЕТРИКИ (KPI)
   - 4–8 ключевых показателей. Для каждого: название, единица, формула словами,
     целевая зона (что считаем «хорошо»).
   - Если не знаю формулу — предложи разумную и дай согласовать.

5. ТИПОВЫЕ ВОПРОСЫ АССИСТЕНТУ
   - 5–10 вопросов, которые мои пользователи хотят задавать в свободной форме.

6. СТЕК
   - Есть ли ограничения (только статический фронт / обязателен Python /
     нельзя внешние API / нужен Docker и т.п.)?
   - Если нет — предложи дефолт: Vanilla HTML+JS+CSS + ApexCharts (+ Node-бэкенд,
     если нужен AI-ассистент; Python для прогноза).

7. БРЕНД И ЯЗЫК
   - Цветовая гамма (или «как в примере kit»).
   - Логотип (путь или ссылка).
   - Язык интерфейса (BCP-47, напр. ru-RU).
   - Валюта (ISO-4217) если есть денежные метрики.

8. AI-РЕЖИМ И ПРИВАТНОСТЬ
   - Данные локальные, можно ли отправлять в облачную LLM?
   - Если можно — какой провайдер (OpenRouter / OpenAI / Anthropic / локальная
     модель). Если нет — только локальный fallback.

9. ПРОГНОЗ
   - Нужен ли прогноз временных рядов?
   - Если да — по каким рядам.

По завершении всех 9 блоков:

1. Покажи мне итоговый PROJECT_BRIEF.md.
2. Сгенерируй первые черновики трёх файлов в корне моего проекта:
   - source-manifest.yaml (по kit/templates/source-manifest.example.yaml),
   - metric-catalog.yaml (по kit/templates/metric-catalog.example.yaml),
   - brand.config.yaml (по kit/templates/brand.config.example.yaml).
3. Подсвети TODO-места, где я должен уточнить (имена колонок, путь логотипа и
   т.д.).
4. Предложи мне отправить следующий промт: kit/prompts/20-map-data.md.
```
