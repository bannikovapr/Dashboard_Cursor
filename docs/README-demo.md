# Демонстрация дашборда ТОиР

Краткая инструкция, чтобы показ прошёл без сюрпризов на машине докладчика.

## Быстрая проверка

Из корня проекта:

```powershell
npm run demo:check
```

Скрипт проверяет наличие и целостность `data/toir.json` (без запуска сервера).

## За 1–2 дня до демо

1. **Зависимости:** `npm install` в корне репозитория.
2. **Данные:** убедитесь, что в `data/` лежат все нужные `.xlsx` и успешно выполняется `npm run build:dashboard:json`. Если на демо используете уже собранный снимок — положите актуальный `data/toir.json` заранее и на репетиции запускайте с **`START_DASHBOARD_NO_BUILD.cmd`** или `.\scripts\start-dashboard.ps1 -NoRefresh`, чтобы не зависеть от Python/Excel.
3. **Порты:** освободите **8787** (API) и **5173** (статика браузера), либо задайте другие в `.env` / ключ `-Port` у `start-dashboard.ps1` и согласуйте `TOIR_API_URL` в `index.html`, если меняли API.
4. **Сеть и AI:** в `.env` должен быть рабочий `OPENROUTER_API_KEY`, если планируется облачный ответ. Без ключа чат перейдёт на **локальный fallback** (заранее проговорите это зрителям). Первый ответ после старта может занять **десятки секунд** (инициализация DLP/ML на сервере) — один раз «простреляйте» вопрос до демо.
5. **Вход в дашборд:** если включён `DASHBOARD_AUTH_ENABLED=true`, на экране появится форма входа. Для простого показа чаще оставляют **`DASHBOARD_AUTH_ENABLED=false`** или готовят стикер с логином/паролем из `.env`.

## В день демо (за 30–60 минут)

1. Закройте старые процессы Node/PowerShell, которые могли оставить занятыми порты.
2. Запуск (выберите один вариант):
   - **Браузер + статика:** `START_DASHBOARD.cmd` или `.\scripts\start-dashboard.ps1` — откроется вкладка на `http://localhost:5173` (или ваш порт).
   - **Одно окно, без отдельной статики:** `npm run desktop` — API поднимается вместе с окном; удобно для записи экрана.
3. Пролистайте вкладки: **Сводка → Затраты → Надёжность → Оборудование → Диагностики → Отчёт ТОиР**, переключите период и класс один раз.
4. Задайте **один** тестовый вопрос AI (режим Агент и при желании Быстрый ответ).

## Идеи сценария (что показать)

- Фильтры **период / класс** и реакция KPI и графиков.
- **Диагностики** — сработавшие правила и краткие выводы.
- **Отчёт ТОиР** — создание/открытие отчёта, при необходимости AI-правка (нужен ключ OpenRouter и стабильная сеть).
- Кнопка **«Подгрузить свежие данные»** — если меняли `toir.json` на диске без перезапуска страницы.

## Если что-то пошло не так

- Лог тихого запуска: `%TEMP%\toir-dashboard-launch.log`.
- API не поднимается: консоль, где запущен `node server/index.js`, или проверка `http://localhost:8787/health` в браузере.
- Пустые графики: проверьте, что `data/toir.json` не пустой и соответствует ожидаемой схеме (`npm run demo:check`).

## Конфиденциальность

На публичной демо не открывайте реальные персональные данные без разрешения; при необходимости используйте обезличенный набор Excel/`toir.json`.
